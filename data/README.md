# Datasets

Ce dossier contient des jeux de données légers et des instructions de récupération.

- `iris` : disponible via `sklearn.datasets.load_iris`
- `housing` : `sklearn.datasets.fetch_california_housing`
- `MNIST` / `CIFAR-10` : disponibles via TensorFlow/Keras ou torchvision
- NLP datasets : via `datasets` (Hugging Face)
