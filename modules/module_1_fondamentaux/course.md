# Cours détaillé - Fondamentaux

## Concepts clés
- **IA** : systèmes qui réalisent des tâches cognitives.
- **ML** : sous-domaine de l'IA qui apprend à partir des données.
- **DL** : sous-domaine du ML basé sur des réseaux de neurones profonds.

## Types d'apprentissage
- **Supervisé** : données étiquetées (ex: classification).
- **Non supervisé** : structure cachée (ex: clustering).
- **Par renforcement** : agent + récompense.

## Préparation des données
- Nettoyage des valeurs manquantes
- Encodage des variables catégorielles
- **Feature scaling**: StandardScaler / MinMaxScaler

## Exemple mathématique (régression linéaire)
\[
\hat{y} = w^T x + b
\]
Objectif: minimiser l'erreur quadratique moyenne (MSE).
