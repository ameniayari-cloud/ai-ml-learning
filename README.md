## Guide de démarrage
1. Suivez `setup.md` pour installer l'environnement.
2. Démarrez par `modules/module_1_fondamentaux/README.md`.
3. Faites les exercices de `exercises/` puis comparez avec `solutions/`.
4. Réalisez les projets dans `projects/`.
5. Utilisez les notebooks dans `notebooks/` pour pratiquer de façon interactive.

## Structure du dépôt
```text
modules/      # Cours théoriques par module
projects/     # Projets pratiques guidés
exercises/    # Exercices progressifs
notebooks/    # Notebooks Jupyter (modules + projets)
data/         # Jeux de données / instructions
solutions/    # Solutions d'exercices et projets
```
