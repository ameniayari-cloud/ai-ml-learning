# Projet 09 - Capstone: Application ML complète (Vision + NLP)

## Objectif
Concevoir une application intégrée combinant vision et NLP, avec déploiement API.

## Spécifications
- Pipeline vision (classification image)
- Pipeline NLP (analyse texte)
- API unifiée Flask/FastAPI
- Sauvegarde/chargement des modèles
- Mesure de performance d'inférence

## Données
- Vision: CIFAR-10/MNIST
- NLP: dataset de sentiment ou corpus d'intentions

## Fichiers
- `starter.py`
- `solution.py`
- Notebook: `../../notebooks/projects/project_09_capstone.ipynb`
